Subtitle Auto Align

Automatically runs ffsubsync on newly downloaded subtitles for movies and TV episodes, writing an aligned copy alongside the original.

Align new subtitles as they appear. Does not affect "Align all subtitles" below.

Watch these libraries

New subtitles in unticked libraries are not aligned automatically. Libraries you add later are watched.

Analyse new videos in advance

New movies and episodes in ticked libraries are analysed as soon as Jellyfin adds them, so their first subtitle aligns in seconds. This uses CPU for every new video, including ones you never add subtitles to. Later subtitles for a video are always fast, ticked or not.
Leave empty to auto-detect: uses the ffsubsync binary bundled with this plugin (Linux x64), or falls back to "ffsubsync" on PATH. Set an explicit path to override.
Optional extra CLI arguments, e.g. --max-offset-seconds 60

Existing subtitles

Search all library folders (including subfolders) for subtitle files next to their videos and align every one that doesn't have an aligned copy yet. This runs the "Align all subtitles" scheduled task; you can follow its progress, cancel it or schedule it under Dashboard > Scheduled Tasks.
